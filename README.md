## 1. Как поднять окружение

1. Перейдите в папку со стендом:
   ```bash
   cd _stand
   ```
2. Запустите контейнеры ClickHouse и Metabase в фоновом режиме:
   ```bash
   docker compose up -d
   ```

### Используемые порты:
* **ClickHouse (HTTP):** `8123`
* **Metabase:** `3000`

---

## 2. Исходные файлы и сырьё

Данные хранятся в папке: `data/raw/`

### Описание полей файла `orders.csv`:
* `order_id` (String) — Уникальный идентификатор заказа
* `order_date` (Date) — Дата совершения покупки
* `customer_id` (String) — Идентификатор клиента
* `product_id` (String) — Идентификатор товара
* `category` (String) — Категория товара
* `quantity` (Int32) — Количество купленного товара
* `price` (Float64) — Цена за единицу товара
* `revenue` (Float64) — Общая сумма позиции (`quantity * price`)
