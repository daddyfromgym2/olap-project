При повторном запуске скрипта `ddl_duckdb.sql` таблицы полностью очищаются (`DROP TABLE IF EXISTS`), что гарантирует **защиту от удвоения и раздувания продаж**.

2. Битые строки (пустые ключи): `0`
3. Главная метрика (`SUM(revenue)`): **39 400.00**

## 6. Логирование и ELT процессы (Задание З05)

Создан автоматизированный SQL-скрипт загрузки данных `sql/load_and_check.sql`. Он реализует ELT-пайплайн по принципу: Полное пересоздание таблиц (Идемпотентность) -> Проверка качества (Data Quality) -> Загрузка измерений -> Загрузка фактов.

### Принцип идемпотентности:
При повторном запуске скрипта срабатывают команды `DROP TABLE IF EXISTS` и `CREATE TABLE`, которые полностью пересоздают структуру с нуля. Это гарантирует защиту от дублирования первичных ключей и **не раздувает факт при перезапусках**.
