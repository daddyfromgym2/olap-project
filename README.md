## 1. Как поднять окружение

1. Перейдите в папку со стендом:
   ```bash
   cd _stand
   ```
2. Запустите контейнеры ClickHouse и Metabase в фоновом режиме:
   ```bash
   docker compose up -d
   ```

### Используемые порты:
* **ClickHouse (HTTP):** `8123`
* **Metabase:** `3000`

---

## 2. Исходные файлы и сырьё

Данные хранятся в папке: `data/raw/`

### Описание полей файла `orders.csv`:
* `order_id` (String) — Уникальный идентификатор заказа
* `order_date` (Date) — Дата совершения покупки
* `customer_id` (String) — Идентификатор клиента
* `product_id` (String) — Идентификатор товара
* `category` (String) — Категория товара
* `quantity` (Int32) — Количество купленного товара
* `price` (Float64) — Цена за единицу товара
* `revenue` (Float64) — Общая сумма позиции (`quantity * price`)

## 5. Работа с DuckDB (Задание З03)

Для развертывания витрины в DuckDB используется CLI или встроенный клиент. Способ загрузки полностью воспроизводим.

### Как запустить скрипты и загрузить данные:
При повторном запуске скрипта `ddl_duckdb.sql` таблицы полностью очищаются (`DROP TABLE IF EXISTS`), что гарантирует **защиту от удвоения и раздувания продаж**.

### Вывод проверочных запросов:
1. Количество строк в таблицах:
   * `fact_orders`: 5 строк (совпадает с файлом сырья)
   * `dim_products`: 4 строки (уникальные товары)
   * `dim_customers`: 4 пользователя (уникальные клиенты)
2. Битые строки (пустые ключи): `0`
3. Главная метрика (`SUM(revenue)`): **39 400.00**
